## Versione desktop

Versione sorella desktop in **Java + JavaFX**: [javilesaca/memoryCard](https://github.com/javilesaca/memoryCard).
Scarica l'installer per il tuo sistema ([Windows `.exe`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card-1.0.1.exe) · [macOS `.dmg`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card-1.0.1.dmg) · [Linux `.deb`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card_1.0.0.deb)) o sfoglia [tutte le release](https://github.com/javilesaca/memoryCard/releases). Nessuna installazione Java richiesta.


## Backend

Classifica su **Firebase Firestore** con fallback `localStorage`. Migrato da Supabase perché il piano gratuito metteva in pausa il database per inattività.
