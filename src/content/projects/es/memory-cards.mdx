## Versión de escritorio

Existe una versión hermana de escritorio en **Java + JavaFX** (misma mecánica, interfaz FXML con CSS y sonidos): [javilesaca/memoryCard](https://github.com/javilesaca/memoryCard).
Descarga el instalador para tu sistema ([Windows `.exe`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card-1.0.1.exe) · [macOS `.dmg`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card-1.0.1.dmg) · [Linux `.deb`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card_1.0.1_amd64.deb)) o mira [todas las releases](https://github.com/javilesaca/memoryCard/releases). No necesitas tener Java instalado.


## Backend

Ranking en **Firebase Firestore** con fallback a `localStorage`. Se migró desde Supabase porque su plan gratuito pausaba la base de datos por inactividad.
