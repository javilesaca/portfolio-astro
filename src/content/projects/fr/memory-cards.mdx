## Version bureau

Version soeur bureau en **Java + JavaFX** : [javilesaca/memoryCard](https://github.com/javilesaca/memoryCard).
Télécharge l'installeur pour ton système ([Windows `.exe`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card-1.0.1.exe) · [macOS `.dmg`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card-1.0.1.dmg) · [Linux `.deb`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card_1.0.0.deb)) ou parcours [toutes les releases](https://github.com/javilesaca/memoryCard/releases). Aucune installation Java requise.


## Backend

Classement sur **Firebase Firestore** avec repli `localStorage`. Migré depuis Supabase car l'offre gratuite mettait la base en pause par inactivité.
