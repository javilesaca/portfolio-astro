## Desktop version

A sibling desktop version in **Java + JavaFX** exists (same mechanics, FXML UI with CSS and sounds): [javilesaca/memoryCard](https://github.com/javilesaca/memoryCard).
Download the installer for your system ([Windows `.exe`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card-1.0.1.exe) · [macOS `.dmg`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card-1.0.1.dmg) · [Linux `.deb`](https://github.com/javilesaca/memoryCard/releases/latest/download/memory-card_1.0.1_amd64.deb)) or browse [all releases](https://github.com/javilesaca/memoryCard/releases). No Java install needed.


## Backend

Ranking on **Firebase Firestore** with `localStorage` fallback. Migrated from Supabase because its free tier paused the database on inactivity.
